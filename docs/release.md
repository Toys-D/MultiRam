# MultiRam 1.5.0

Версия приложения: **1.5.0**, сборка **73**. macOS **14 или новее**, Intel и Apple Silicon.

**Проверка обновлений.** Раз в сутки MultiRam спрашивает у GitHub номер последнего релиза (`api.github.com/repos/Toys-D/MultiRam/releases/latest`). Если версия новее, появляется окно с кнопками «Скачать» (открывает страницу релиза), «Позже» и «Пропустить эту версию». В «Основных» — переключатель и кнопка «Проверить сейчас». Для этого у программы появилось разрешение песочницы `network.client`; история буфера обмена никуда не отправляется.

## Изменения 1.4.0

**Фильтры.** Над списком — «Всё / Текст / Картинки / Файлы». Фильтр действует и на закреплённые записи и сбрасывается на «Всё», когда окно закрывается.

**Предпросмотр.** Пробел (когда поле поиска пустое) или ⌘Y открывает выбранную запись в боковой панели, повторное нажатие закрывает.

**Склейка нескольких записей.** Shift+↑/↓ или ⌘+щелчок выделяют несколько записей (номера показывают порядок); Return вставляет их текст одним блоком, каждую запись с новой строки. Картинки и файлы при склейке пропускаются.

**Срок хранения.** «Хранение → Хранить записи»: всегда, 1 день, неделю, месяц, 3 месяца или год. Более старые незакреплённые записи удаляются при запуске, раз в час и при смене срока.

**Цвет закреплённых.** Закреплённые строки слегка подкрашены; в «Окне истории» подсветку можно выключить и выбрать цвет (по умолчанию — цвет логотипа).

## Изменения 1.2.1

**Автоматическая вставка после выдачи разрешения.** macOS запоминает отказ в отправке нажатий для уже запущенного процесса и не пересматривает его, даже когда MultiRam снова включён в «Универсальном доступе». Поэтому окно «Разрешите MultiRam вставлять автоматически» появлялось раз за разом, сколько бы запись ни удаляли и ни добавляли, пока программу не перезапускали вручную. Теперь MultiRam сам замечает включённый доступ и перезапускается: в течение часа после окна с просьбой о разрешении — автоматически, а если доступ включили позже — при следующей вставке предлагает перезапуск одной кнопкой. Новый экземпляр дожидается завершения старого, поэтому сочетания клавиш и запись буфера обмена не дублируются.

**Подпись релиза.** DMG и ZIP подписаны сертификатом Apple Development. Требование подписи ссылается на сертификат, а не на хеш сборки, поэтому разрешение «Универсальный доступ» сохраняется при обновлении на следующие версии с той же подписью — и из DMG, и при локальной установке. Предыдущие DMG были подписаны ad hoc: такая сборка, установленная поверх подписанной сертификатом, для macOS другая программа, и разрешение сбрасывалось. Если до обновления стояла сборка из DMG 1.2.0 или старше, после установки 1.2.1 разрешение нужно выдать ещё один раз; дальнейшие обновления его не сбрасывают.

### Изменения 1.2.0

**Option + V в полях паролей.** Пока курсор стоит в поле пароля, браузер включает защищённый ввод, и macOS не передаёт программам сочетания только с Option. Поэтому на страницах с полем входа Option + V не открывал историю. Обойти это ограничение нельзя, поэтому добавлено запасное сочетание **Control + Option + V**: macOS доставляет его и в полях паролей. Пока основное сочетание заблокировано, на значке в строке меню появляется замочек, а подсказка и меню значка называют программу, включившую защищённый ввод. В настройках оба сочетания можно изменить; совпадающее запасное сочетание сбрасывается, а для сочетаний только с Option показывается предупреждение.

**Открыть картинку в другой программе.** Под картинкой в боковой панели появились кнопки графических редакторов и просмотрщиков, найденных на Mac: программа по умолчанию первой, затем недавно использованные. Меню «Ещё» содержит остальные редакторы, все подходящие программы, выбор любой программы и «Показать в Finder». Программе передаётся копия с исходными байтами; простой TIFF без потерь превращается в PNG. Копия доступна только для чтения, лежит во временной папке MultiRam вне контейнера, удаляется через сутки и при очистке истории.

Исправлено: запись буфера обмена больше не останавливается, пока открыто окно выбора программы или системное предупреждение; после отмены выбора фокус возвращается в прежнюю программу; перелистывание записей повторным нажатием V при зажатом Option снова работает после очистки и повторной записи сочетания в настройках. Недостающие строки в 38 языках показываются по-английски вместо технических ключей.

## Что включено

- История по Option + V, настройки через значок в строке меню.
- Закрепление прямо в строке, тонкие разделители, текст до четырёх строк с многоточием.
- Боковая панель с полным текстом или большой картинкой по стрелке в строке.
- Кнопки «Открыть в…» для картинок и запасное сочетание Control + Option + V для полей паролей.
- Кнопка очистки рядом с поиском; числовые сочетания Command + 1…9 удалены.
- Окно остаётся в пределах экрана, в том числе у нижнего края.
- Название MultiRam и иконка с прозрачным фоном.
- Автоматические обновления отключены, библиотека Sparkle в сборку не входит.

На чистой установке применяются согласованные настройки: история 22 записи, высота изображений 100, окно 450 × 800, открытие у курсора, закреплённые записи сверху, сортировка по первому копированию, вставка по выбору записи. Уже сохранённые настройки пользователя имеют приоритет. Личная история, закрепления и разрешения этого Mac в установщик не входят.

## Универсальная сборка

```sh
xcodebuild -project MultiRam.xcodeproj -scheme MultiRam \
  -configuration Release -destination 'generic/platform=macOS' \
  -derivedDataPath /tmp/multiram-release/DerivedData \
  'ARCHS=arm64 x86_64' ONLY_ACTIVE_ARCH=NO \
  CODE_SIGN_IDENTITY=- CODE_SIGN_STYLE=Manual DEVELOPMENT_TEAM= build
python3 scripts/package-release.py \
  --app /tmp/multiram-release/DerivedData/Build/Products/Release/MultiRam.app \
  --checkouts /tmp/multiram-release/DerivedData/SourcePackages/checkouts \
  --identity "Apple Development"
```

Результат находится в `releases/MultiRam-1.5.0/`: приложение, DMG, ZIP приложения, инструкции, лицензии, манифест и SHA-256. Скрипт сохраняет исходную сборку, добавляет лицензии зависимостей в копию приложения, подписывает её сертификатом из `--identity` без отладочных разрешений и проверяет подпись и DMG. Для подписи сертификатом он дополнительно проверяет, что требование подписи ссылается на сертификат, а не на хеш сборки; отметка времени Apple требует сети. Без `--identity` копия подписывается ad hoc. Упаковщик отклоняет сторонние динамические библиотеки, которые Hardened Runtime не загрузит. Повторный запуск требует нового пустого каталога `--output`.

## Публикация на GitHub

Кнопка «Скачать» в README ведёт на `releases/latest/download/MultiRam.dmg`, поэтому к каждому релизу прикладывается копия DMG с постоянным именем `MultiRam.dmg`. Версию в тексте кнопки README нужно обновить.

```sh
cp releases/MultiRam-1.5.0/MultiRam-1.5.0.dmg .build/GitHubRelease/MultiRam.dmg
gh release create v1.5.0 --repo Toys-D/MultiRam --target <commit> --title "MultiRam 1.5.0" \
  --notes-file .build/GitHubRelease/notes.md --latest \
  releases/MultiRam-1.5.0/MultiRam-1.5.0.dmg .build/GitHubRelease/MultiRam.dmg \
  releases/MultiRam-1.5.0/MultiRam-1.5.0.app.zip releases/MultiRam-1.5.0/SHA256SUMS.txt
```

Репозиторий публичный: ссылки работают у всех, а программа находит новый релиз через GitHub API (`releases/latest`).

## Установка

Откройте DMG и перетащите MultiRam в Applications. При обновлении сначала завершите ранее запущенный MultiRam. Настройки и история хранятся отдельно от приложения и сохраняются при замене `.app` с тем же идентификатором.

Релиз подписан сертификатом Apple Development (команда 4TS5LL8779), без Developer ID и нотариального заверения Apple. Если macOS блокирует первый запуск, откройте «Системные настройки → Конфиденциальность и безопасность» и разрешите открытие MultiRam. [Инструкция Apple](https://support.apple.com/en-us/102445).

Для автоматической вставки предоставьте MultiRam доступ в «Конфиденциальность и безопасность → Универсальный доступ» (в macOS 27 — «Управление устройством и доступ к данным») при первом запросе. Как только доступ включится, MultiRam перезапустится сам: macOS применяет разрешение только к новому процессу. Если вставка всё равно не работает, завершите MultiRam и откройте его снова. Разрешение назначается на каждом Mac отдельно и сохраняется при обновлениях с той же подписью. После замены сборкой с другой подписью (например, ad hoc) удалите старую запись MultiRam из «Универсального доступа» и добавьте установленное приложение заново.

Для распространения без предупреждения о неопознанном разработчике нужен сертификат Developer ID Application, подпись вложенного кода и приложения, затем notarization и stapling. Эти действия не выполнены в текущем релизе.

## Подпись и разрешение «Универсальный доступ»

Разрешение «Универсальный доступ» привязано к назначенному требованию подписи. У ad hoc подписи оно состоит из cdhash бинарника, поэтому каждая пересборка делает ранее выданное разрешение недействительным, хотя переключатель в настройках остаётся включённым. Требование подписи сертификатом Apple Development строится на идентификаторе приложения и сертификате и переживает пересборки. Поэтому релиз упаковывается с `--identity`, и одна и та же подписанная сборка идёт и в DMG, и в локальную установку:

```sh
osascript -e 'tell application id "local.multiram.MultiRam" to quit'
rm -rf /Applications/MultiRam.app && cp -R releases/MultiRam-1.5.0/MultiRam.app /Applications/
codesign -dvv /Applications/MultiRam.app 2>&1 | grep 'Authority=Apple Development'
open /Applications/MultiRam.app
```

Подписи нельзя смешивать: ad hoc сборка, установленная поверх подписанной сертификатом (и наоборот), для macOS другая программа, и разрешение сбрасывается. Сертификат действует до 4 ноября 2027 года. Продлить его можно без окна Xcode: сборка с `-allowProvisioningUpdates CODE_SIGN_STYLE=Automatic DEVELOPMENT_TEAM=4TS5LL8779` выпускает новый сертификат; он сохраняет имя, и требование подписи остаётся прежним.

macOS запоминает отказ в отправке нажатий для запущенного процесса. Если разрешение выдали, пока MultiRam работает, вставка заработает только в новом процессе, поэтому MultiRam перезапускается сам (`AccessibilityGrantWatcher`, `AppRelauncher`). Песочница не передаёт аргументы запуска новому экземпляру, поэтому номер старого процесса передаётся через настройки программы (ключ `relaunchRequest`, действует 30 секунд).

## Проверка вставки перед распространением

Проверяйте именно приложение, скопированное из окончательного DMG в Applications, поскольку другая сборка может иметь другое разрешение macOS. Откройте пустой тестовый документ, нажмите Option + V и щёлкните по текстовой записи. Текст должен появиться в документе без дополнительного Command + V. Повторите для закреплённой записи и выбора клавишей Return.

При отсутствии разрешения должно появиться объяснение, а выбранная запись должна оставаться в буфере обмена. После выдачи разрешения повторите проверку в документе. Модульные тесты проверяют отправку пары клавиш вставки и отказ от отправки без разрешения; UI-тест `testAutomaticPasteExplainsMissingPermission` требует отсутствующего разрешения у тестовой сборки и проверяет сообщение и сохранение выбранного текста. Модульные тесты `PasteAccessTests`, `AccessibilityGrantWatcherTests` и `AppRelauncherTests` проверяют выбор между «нужно разрешение» и «нужен перезапуск», перезапуск после выдачи доступа и передачу номера старого процесса новому. Эти тесты не заменяют проверку вставки в другом приложении из установленного релиза.
